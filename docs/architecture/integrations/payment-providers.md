## PayPal

- **Used for:** Payment processing
- **Integration Method:** SDK
- **Available Operations:** Payment
- **Sandbox:** Yes
- **Notes:** Supports multiple payment methods, returns transaction results to the system

## Monobank

- **Used for:** Payment processing
- **Integration Method:** REST API
- **Available Operations:** Payment
- **Sandbox:** No
- **Notes:** —

## Apple Pay

- **Used for:** Payment processing
- **Integration Method:** REST API
- **Available Operations:** Payment
- **Sandbox:** Yes (requires Apple Developer account)
- **Notes:** Supported natively in Safari and most modern browsers


## Stripe (Google Pay)
- **Used for:** Payment processing
- **Integration Method:** SDK
- **Available Operations:** Payment
- **Sandbox:** Yes 
- **Notes:** Google Only
